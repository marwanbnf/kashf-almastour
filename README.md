# اكشف المستور 🔍

لعبة ذاكرة جماعية للمسابقات: الفرق تكشف الكروت وتطابق البطاقات وتجمع أغلى الأغراض.

- **العب:** https://marwanbnf.github.io/kashf-almastour/
- افتح الرابط على الشاشة أو البروجكتر، وخلّ المقدم يصوّر الباركود بجواله عشان يتحكم باللعبة.
- التحكم من الجوال يعتمد على Firebase Realtime Database (مشروع `kashf-almastour`). قواعد القاعدة في `database.rules.json`.
